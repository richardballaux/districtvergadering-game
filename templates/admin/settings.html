Tips voor codes
  • Kies korte, makkelijk te typen codes (4–8 letters).
  • Gebruik alleen hoofdletters en cijfers (geen spaties).
  • Print de code groot uit of schrijf hem op een kaartje.
  • Leg het kaartje pas neer vlak voor het spel start.
  • Verberg de code ergens logisch bij de locatie.
